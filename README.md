# Commit convention

| Tag          | When to use it                                      |
| ------------ | --------------------------------------------------- |
| `[feat]`     | New domain functionality                            |
| `[fix]`      | Bug fix                                             |
| `[build]`    | Build, dependencies, tooling (pom, quality plugins) |
| `[test]`     | Tests only                                          |
| `[refactor]` | Restructuring without behavior change               |
| `[docs]`     | Documentation                                       |
| `[chore]`    | Miscellaneous maintenance                           |
